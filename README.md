\# StockVision — Interactive Scilab GUI



StockVision is an interactive Scilab GUI for stock forecasting and market analysis. It fits Linear Regression, AR time-series, and Exponential Smoothing (Holt) models, compares their performance using real metrics and 3-fold walk-forward validation, and backtests BUY/SELL signals against a Buy \& Hold strategy.



\## Features



\- Interactive Scilab graphical user interface

\- Linear Regression, AR, and Holt Exponential Smoothing models

\- Model comparison using RMSE and other metrics

\- 3-fold walk-forward validation

\- BUY/SELL signal generation

\- Backtesting against Buy \& Hold

\- Transaction costs and slippage analysis

\- Risk and performance analysis

\- Sample outputs and screenshots

\## Requirements



\- Scilab

\- A desktop system capable of running Scilab



\## How to Run



1\. Open Scilab.

2\. Navigate to `01\_Source\_Code/scilab\_gui\_app/`.

3\. Run the main `.sce` file.

4\. Use the GUI controls to select a dataset, choose a forecasting model, run analysis, and view results.



For complete instructions, refer to `02\_Documentation/StockVision\_README.pdf`.
